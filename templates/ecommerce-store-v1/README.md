# Forma — Professional E-commerce Storefront

A responsive, polished storefront starter for a modern retail or lifestyle brand. Built with plain HTML, CSS and JavaScript so it can be hosted almost anywhere without a build step.

## Included
- Editorial homepage with hero, brand story and newsletter sections
- Product catalogue with category filters, search and price sorting
- Responsive product cards and quick-add actions
- Shopping bag drawer with quantity controls, remove action and subtotal
- Cart persistence with browser localStorage
- Mobile, tablet and desktop layouts
- Accessible labels, semantic sections and keyboard Escape support

## Run locally
1. Extract the project folder.
2. Open `index.html` in a modern browser, or serve the folder with a local static server.
3. No package installation or build command is required.

## Customize
- Edit the `products` array in `app.js` to add products, prices, categories and image URLs.
- Replace the Forma name, copy, email and brand colors in `index.html` and `styles.css`.
- Replace demo product photos with images you own or are licensed to use.
- Update shipping thresholds and currency formatting to match your market.

## Production integrations required
This is a front-end storefront starter, not a complete commerce backend. Before accepting real orders, connect:
- A product and inventory API / database
- A secure server-side checkout integration (e.g. Paystack or Stripe)
- Server-side order creation, payment verification and webhook handling
- Shipping, tax, returns and transactional email workflows
- Privacy, terms and refund policy pages

The checkout button is intentionally demo-only and does not collect payment details. Never place secret API keys in browser JavaScript.

## Project files
- `index.html` — page structure
- `styles.css` — design system and responsive styling
- `app.js` — product catalogue, filters, cart and newsletter demo
