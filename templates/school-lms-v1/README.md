# Northstar Academy — School & LMS Dashboard

A responsive student learning portal dashboard starter built with HTML, CSS and vanilla JavaScript. It is a front-end demo that can be opened locally without a build step.

## Features
- Student overview with course, learning-hour, task and grade metrics
- Course progress cards
- Upcoming class schedule with day navigation
- Interactive assignment completion toggles
- Learning progress visualization
- Responsive collapsible mobile sidebar
- Accessible labels and semantic page regions

## Run locally
Open `index.html` in a modern browser, or serve the directory with a static web server. No package manager or build command is required.

## Customize
- Replace Northstar Academy and student identity in `index.html`.
- Update course, schedule and assignment demo data in `app.js`.
- Change theme colors, typography and layout in `styles.css`.
- Replace demo email addresses and support links.

## Important production requirements
This is a UI starter, not a complete learning platform. Before using with real students, implement:
- Secure authentication, role-based access (student, teacher, parent, administrator)
- Backend APIs and database for users, courses, lessons and enrollments
- Assignment submission, file storage, grading and audit history
- Timetable and attendance management
- Notifications and messaging with appropriate privacy controls
- Data protection, backups and safeguarding policies

The displayed metrics and learning records are sample data stored in the front-end source. Assignment toggles only affect the current page session and are not submitted to a server.

## Files
- `index.html` — dashboard markup
- `styles.css` — responsive design system
- `app.js` — sample dashboard data and interactions
