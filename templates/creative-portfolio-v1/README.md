# Studio North — Creative Portfolio

A bold, editorial portfolio starter for independent designers, photographers, art directors and creative studios. Built with HTML, CSS and vanilla JavaScript. No build tooling or package installation is required.

## Features
- Strong typographic landing page and availability indicator
- Selected-work grid with distinct project art directions
- About section, services list and direct email contact
- Responsive layouts for mobile, tablet and desktop
- Lightweight smooth-scroll navigation
- Semantic HTML and editable content

## Run locally
Open `index.html` in a browser, or serve this folder using any static web server.

## Customize before delivery
- Replace Studio North branding and all sample project names/copy.
- Replace CSS-generated artwork with real project imagery where available.
- Update email and social profile links in `index.html`.
- Adjust colors, fonts and spacing in `styles.css`.

## Files
- `index.html` — portfolio structure and content
- `styles.css` — visual design and responsive breakpoints
- `app.js` — navigation behavior and year
