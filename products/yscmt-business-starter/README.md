# Northstar — Business Website Starter

A polished, responsive static business website template created by **YSCMT Enterprise**.

## Included
- Responsive landing page with mobile navigation
- Hero, about, services, approach, and contact sections
- Accessible form labels and reduced-motion support
- Contact form that prepares an email in the visitor's email app
- No build tools, frameworks, or paid dependencies

## Quick start
1. Unzip the package.
2. Open `index.html` in a browser, or serve this folder with any static web server.
3. Replace `hello@example.com` in `script.js` with the business owner's real email.
4. Edit the business name, copy, services, and contact details in `index.html`.
5. Adjust colors and typography in `styles.css`.

For a local preview, run `python3 -m http.server 8080` in this folder and visit http://localhost:8080.

## Before publishing
- Replace the demo brand name and sample copy.
- Set a real contact email.
- Add the business's privacy policy and legal details if collecting personal data.
- Test on mobile and desktop.
- The contact form uses a mailto handoff; it does not store submissions or send them through a server.

## Compatibility
Modern Chrome, Firefox, Safari, and Edge. Plain HTML, CSS, and JavaScript.
