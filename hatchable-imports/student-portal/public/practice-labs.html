Practice Labs

Move beyond reading. These guided challenges help you apply your YSCMT lessons through realistic tasks and portfolio projects. Start at Intermediate, then attempt Advanced when you can explain your approach and test your work.

These labs are independent practice activities. They do not change your course enrolment, lesson-completion record, examination score, or certificate eligibility.

Intermediate Labs

BUILD CONFIDENCE
COMPUTER FUNDAMENTALS

Organise a small office workstation

Plan a reliable computer setup for a small business with three staff members.

  • Compare RAM, storage, CPU and monitor needs for each role
  • Create a clear folder structure and file-naming convention
  • Prepare a backup schedule and a basic device-maintenance checklist
Submit / demonstrate: A one-page equipment plan, folder tree and weekly maintenance checklist.
CYBERSECURITY

Personal security review

Assess the security of accounts and devices that you own or are authorised to manage.

  • Make a list of important accounts and enable MFA where available
  • Review recovery email, phone and active sessions
  • Identify suspicious messages using sender, link and urgency clues
Submit / demonstrate: A redacted security checklist and a short incident-response plan. Never include passwords or recovery codes.
PYTHON PROGRAMMING

Student score manager

Build a command-line program that records student names and scores.

  • Use lists or dictionaries to store records
  • Validate that scores are between 0 and 100
  • Calculate average, highest score and pass/fail status
  • Split the work into reusable functions
Submit / demonstrate: Python source code plus sample input and output for at least five students.
WEB DEVELOPMENT

Responsive business landing page

Create a simple, mobile-friendly website for a fictional local business.

  • Use semantic HTML sections and a labelled contact form
  • Style the layout with Flexbox or CSS Grid
  • Add a JavaScript form check and clear feedback
  • Test keyboard navigation and narrow phone widths
Submit / demonstrate: HTML, CSS and JavaScript files with screenshots at mobile and desktop widths.

Advanced Labs

CREATE A PORTFOLIO PROJECT
COMPUTER FUNDAMENTALS

Design a small-office IT plan

Design a maintainable technology setup for a growing office of ten people.

  • Draw a device and network inventory with a simple topology
  • Specify user roles, update routines and backup rotation
  • Estimate lifecycle costs and identify single points of failure
  • Write a recovery checklist for device loss or failure
Submit / demonstrate: A labelled network diagram, asset register, budget estimate and recovery runbook.
CYBERSECURITY

Threat model a sample web app

Use a fictional application or a local test project you own. Do not probe public systems.

  • List assets, users, trust boundaries and entry points
  • Identify likely threats and rate impact and likelihood
  • Recommend layered controls for authentication, data and backups
  • Write a safe incident-handling and evidence-preservation plan
Submit / demonstrate: A threat-model diagram and risk register. No exploitation or scanning of third-party targets.
PYTHON PROGRAMMING

Build a secure inventory API

Develop a small local API for managing stock items, using a framework you have studied.

  • Create endpoints to add, list, update and archive items
  • Validate input and handle missing records cleanly
  • Use environment variables for configuration and never commit secrets
  • Add automated tests for normal and invalid requests
Submit / demonstrate: Source code, setup instructions, API examples and test results using sample data only.
WEB DEVELOPMENT

Build and publish a full web project

Turn the landing page into a small multi-page application.

  • Separate reusable layout and page components
  • Connect a form to a backend endpoint or safe mock service
  • Add loading, success and error states
  • Check accessibility, responsive behaviour and basic security
  • Document deployment and rollback steps
Submit / demonstrate: A live demo, repository README, screenshots and a short testing checklist.
Good practice and safety: Use sample data in public demos. Do not upload passwords, private student details, payment information or API keys. Cybersecurity exercises must stay on your own devices, local lab environments, or systems where you have clear written permission. Explain what you learned, not just what you built.
